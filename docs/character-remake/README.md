# 두 캐릭터 전체 동작 재제작

승인한 정면 디자인을 참조하여 imagegen으로 걷기/들고 걷기/휴식 원화를 별도 제작하고 실제 게임 시트에 적용했습니다. 기존 픽셀 확대본을 다시 쓰지 않습니다. 두 캐릭터 각각 64×64 셀, 4열×28행, 256×1792 RGBA이며 런타임 몸/의상 네 파일을 교체했습니다.

행: 0–7 걷기 8방향 / 8–15 들고 걷기 8방향 / 16–19 앉기 4방향 / 20–23 들고 앉기 4방향 / 24–27 눕기 4방향. 눕기 방향은 머리 방향입니다. 눕기 그림은 제작했으나 본게임의 눕기 상호작용은 기존처럼 미구현입니다.

생성 원본: *-source.png, lie-up-source.png. 조립 입력: actions-sources.json. 재조립: pnpm exec tsx scripts/assemble-character-actions.ts. 수정 전 시트는 *-pre-actions.png로 보존합니다. 스크립트는 셀별 투명 경계를 추출하고 행별 동일 배율로 64px 셀에 배치하며 가장자리의 포화색 잔상을 제외합니다. 여성 휴식 원화의 앉기/들고 앉기 행 순서를 교정하고 머리 위쪽 눕기는 보정 원화를 사용합니다.

몸/의상은 겹치지 않는 상보 레이어입니다. 새 캐릭터의 실제 피부 픽셀을 기준으로 프레임별 음식 접점을 추출하여 apps/client/src/character-art-grips.json에 저장합니다. shared hand-rig는 슬롯/음식 기본 계약이며 이 64px 캐릭터는 characterArt.ts의 그림별 접점을 사용합니다. 먹기 머리 경계와 이름표 높이도 새 비율에 맞춰 수정했습니다.

게임 확인: 일반 입장에도 새 시트가 적용됩니다. 주소에 ?characterArtReview=actions를 붙이면 두 캐릭터의 다섯 동작을 동시에 보고 방향을 자동 순환합니다. 여성/남성 모든 28행 애니메이션과 음식/접점은 female/review.html, male/review.html에서 확인합니다. in-game-actions*.png는 실제 게임 엔진 캡처입니다. ?characterArtReview=1은 이전 정면 검토 기능이며 현재 위쪽 그림도 새 런타임 그림입니다.

검증: pnpm build, pnpm check:hands. 자동 검사는 224개 비어 있지 않은 프레임, 치수/투명도, 레이어 비중첩, 96개 프레임별 양손 좌표, 기존 계정 전환, 서버 음식 슬롯 동작을 확인합니다. actions-browser-check.json은 실제 Phaser 로딩과 브라우저 오류 검사 결과입니다. 자동 검사가 모든 프레임의 미술적 자연스러움을 보장하지는 않습니다.
