# 3D 지도 편집기

개발 서버(`pnpm dev`)에서 `/park3d/?edit`를 연다. 현재 3100 포트를 사용한다면 `http://localhost:3100/park3d/?edit`다. 편집·저장은 개발 서버에서만 지원한다.

- 나무 종류를 고르고 나무 도구로 클릭하면 해당 칸 중앙에 한 그루를 설치한다. 같은 칸을 다른 종류로 클릭하면 교체된다. 드래그로 여러 나무를 칠하지 않는다.
- 나무 크기 슬라이더로 50~200% 크기를 정한 후 설치한다. 기존 나무는 선택·이동 도구로 선택하고 크기를 조절한 다음 ‘선택 나무 크기 적용’을 누른다. 크기는 이동·저장·되돌리기에도 유지된다. 크기는 높이와 폭을 함께 조절하며, 충돌 칸은 한 칸을 유지한다.
- 벤치·가로등은 설치 도구로 빈 칸에 하나씩 추가한다.
- 선택·이동 도구로 나무·바위·생울타리·울타리·벤치·트럭·가로등을 골라 드래그한다. 벤치는 R로 회전한다. 삭제 모드 버튼을 누른 뒤 지도에서 해당 타일을 클릭하면 장식·벤치·가로등을 바로 지운다. 벤치는 어느 칸을 눌러도 전체가 삭제된다. 삭제 모드는 계속 유지되므로 다른 물건도 차례로 클릭해 지울 수 있다. 선택한 물건은 Delete로도 삭제할 수 있고, 선택이 없을 때 Delete를 누르면 삭제 모드가 켜진다.
- 트럭 배치 도구에서 가게를 고르고 목적지를 클릭한다. 기존 8개 가게를 재배치한다.
- 바닥 타일 도구에서 눈·산책로·광장·얼음·다리·무대를 골라 칸을 클릭한다. 얼음은 이동을 막고, 다른 바닥으로 교체하면 다시 이동할 수 있다.
- 높이 올리기·내리기는 클릭당 0.25씩, 기본 지형 대비 -2~3 범위에서 조절한다. 주변 칸과 부드럽게 이어진다. 높이는 3D 표시용이며 서버 충돌은 2D 타일 규칙을 따른다.
- 오른쪽·가운데 버튼 드래그 또는 방향키로 화면을 옮긴다. 휠로 확대한다.
- Ctrl+Z로 되돌리고 Ctrl+Shift+Z로 다시 적용한다. 점검 후 Ctrl+S로 저장한다.

원본 `assets/maps/park.json`과 미리보기 데이터에 저장되며 이전 지도는 `assets/maps/.backup/`에 남는다. 서버를 재시작해야 변경한 장애물과 벤치 위치가 서버에도 반영된다. 운영 반영에는 빌드·배포가 필요하다.

나무 종류, 독립 가로등, 지형 높이는 지도 최상위 `editor3d`에 저장되며 메인 3D 화면에서도 읽는다. 기존 지도는 그대로 열 수 있다. 기존 나무의 자동 외형은 유지하고 직접 설치하거나 교체한 나무부터 선택한 종류와 고정 크기를 사용한다.

가로등은 종류 목록에서 기존 사각등, 동색 클래식 랜턴, 청록 유리구형, 검정 장식 랜턴, 옆걸이 랜턴, 양팔 랜턴, 원형 갓, 세 갈래 랜턴, 청록 꽃봉오리형 중 하나를 고른 뒤 설치한다. 기존 가로등은 선택·이동 도구로 선택하고 종류를 고른 다음 ‘선택 가로등에 적용’을 누르면 교체된다. 종류 변경도 되돌리기와 저장을 지원한다. 종류가 저장되지 않은 예전 가로등은 기존 사각등으로 표시된다.

메인 공원과 편집기는 `apps/client/park3d/world.js`의 동일한 지형·소품 생성기를 사용한다. 겨울나무 10종(설송·가문비·참나무·느티나무·미루나무·자작나무·상고대·설화목·전정목·어린 겨울나무), 바위, 생울타리, 울타리, 눈둔덕, 풀, 목교 난간, 벤치, 트럭과 부속 가로등을 메인 모델로 표시한다. 편집 모드는 메인과 같은 원근 투영과 화면 해상도를 사용한다. 지형·벤치·트럭을 바꾸면 메인과 같은 높이 계산까지 다시 적용한다.

개발 환경에 Playwright가 있으면 `PARK_REVIEW_URL=http://localhost:3100 node scripts/review-map-editor.cjs`로 메인과 편집기의 전체 소품 지오메트리·배치·지형 높이가 일치하는지, 편집 후 되돌리기로 동일한 모습이 복구되는지 검사할 수 있다.

겨울나무는 `apps/client/park3d/trees.js`에서 줄기·가지·잔가지·눈을 하나의 모델로 만들고, `world.js`에서 나무 종류별로 인스턴싱한다. 낙엽수의 큰 공 모양 수관은 제거했다. 설송·가문비는 가지마다 작은 비대칭의 둥근 잎 뭉치와 짧게 뾰족한 잎을 섞고, 꼭대기는 돌출된 화살촉 없이 주변 잎과 이어진 수관으로 표현한다. 눈은 잎 뭉치의 윗면에 얹힌다. 기존 `bare0`~`bare3` 저장값도 새 겨울나무 모델로 표시된다. 사진처럼 갈색·회색·흰 수피와 가지 위에 쌓인 눈, 상고대를 구분했다. `bare4`~`bare7`은 상고대·설화목·전정목·어린 나무다. 지도 장애물과 위치는 그대로 사용한다.

[나무 10종 미리보기](park-trees/winter-tree-catalog.png). `node scripts/review-park-trees.cjs`는 실제 Three.js 모델을 렌더링해 이 미리보기와 모델별 검사 결과를 다시 만든다. 선택적으로 `PARK_REVIEW_FONT`에 한글 글꼴 경로를 지정할 수 있다.

바닥 종류는 눈·잔디, 산책로, 잔디와 길 연결, 호수 주변, 기존 바닥으로 묶었다. 종류를 고르면 미리보기가 바뀌고 바닥 도구가 자동으로 선택된다. [겨울 바닥 25종 안내](park-ground/README.md)와 [미리보기](park-ground/winter-ground-catalog.png)에서 재질과 연결 예시를 비교할 수 있다. 추가 재질은 `editor3d.groundStyles`로 저장한다.
