# 겨울 간식 리메이크

17종 모두 실제 음식의 형태·재료가 읽히도록 다시 제작했다. 귀여움은 둥근 비율과 따뜻한 색, 밝은 하이라이트로 표현하고 음식에 임의의 얼굴은 붙이지 않았다.

## 결과와 검토

- `../../assets/sprites/food/`: 기존 계약과 같은 36×12 PNG. 프레임당 12×12, 섭취 3단계, 손 접점 (6,9).
- `../../assets/sprites/food-hd/`: 384×128 PNG. 프레임당 128×128, 메뉴·손 목록·통계 아이콘용.
- `review.html`: 17종의 이전/이후, 3단계, 12px 축소본, 밝은/어두운/체크 배경 비교.
- `preview.png`: 전체 음식 첫 단계 모음.
- `sources/`: 내장 image_gen 도구로 만든 투명 원본. 원본 알파를 유지한다.
- `before/`: 교체 전 17개 시트.
- `prompts.json`: 사용한 공통 스타일 및 음식별 최종 프롬프트 전문.

## 재조립

```sh
pnpm gen:food-art
pnpm check:food
pnpm check:hands
pnpm build
```

모든 단계에 동일한 변환을 적용해 먹을 때 음식이 재정렬되지 않도록 한다. 알파를 반영한 면적 샘플링으로 12px/128px를 만들고, 12px는 선명한 픽셀 경계로 출력한다. 생성기가 남긴 거의 투명한 가장자리 잡색은 샘플링에서 제외한다. 손 접점에 재료가 없으면 재조립이 실패한다.

메인 SD 화면과 `/park3d/`의 음식 메뉴는 고해상도 시트를 직접 읽는다. `/park3d/`의 손에 든 2D 음식은 새 12px 파일을 읽는다. 메인 SD 화면의 손에 든 음식도 `food-hd`를 사용한다. `apps/client/src/sd/food-sprites.js`에서 128px 프레임을 분리해 캐시하고 카메라를 바라보는 스프라이트로 표시한다. Meshy·기본 SD 인형 모두 손 앵커를 따라가며 서버의 섭취 단계(0~2)에 맞춰 바뀐다. 손 접점은 시트의 (6/12, 9/12)이며, 투명 영역은 깊이를 가리지 않고 음식 자체는 캐릭터·배경의 깊이 판정을 따른다.

`pnpm gen:food`는 이미 있는 음식 파일을 보존한다. 새 음식이 없는 경우에만 임시 그림을 만들고 트럭은 기존 방식으로 생성한다.

선택적 브라우저 검토: Playwright를 사용할 수 있는 환경에서 `node scripts/review-food-art.cjs`. 17개 카드·51개 이미지 로드와 배경 전환을 확인하고 데스크톱/모바일 스크린샷을 저장한다.

이번 검증에서 `pnpm check:food`와 전체 빌드, 브라우저 이미지 로드 검사는 통과했다. `pnpm check:hands`는 음식 교체 전부터 캐릭터 프롬프트 문서의 손 좌표 불일치로 실패했다. 음식의 크기·알파·3단계 차이·손 접점 검증은 `check:food`에서 별도로 통과했다. 시스템에 한글 폰트가 없는 브라우저 검토 환경에서는 `PARK_REVIEW_FONT`로 로컬 한글 TTF를 지정할 수 있다.

## 메인 게임 손 음식 적용 확인

`pnpm check:food`와 `pnpm --filter @park/client build` 통과. 브라우저에서 음식 17종·51프레임의 로드·투명도·재질 재사용을 확인하고, Meshy 세 종류와 기본 SD 인형 양손의 3단계 전환 및 손 접점 유지를 확인했다. `held-food-front.png`, `held-food-rotated.png`는 실제 게임의 캐릭터 생성·자세 함수를 사용한 정면/회전 렌더링이며, 결과는 `held-food-check.json`에 기록했다.

손 움직임 회귀 검사는 `scripts/review-food-motion.cjs`를 사용한다(개발 서버 및 Playwright 필요, `PARK_REVIEW_URL`로 주소 지정). 4종 캐릭터의 양손에서 정지 자세의 누적 회전이 없고, 먹는 손만 팔꿈치를 굽혀 올라가는지 검사한다. `held-food-holding.png` / `held-food-eating.png`와 `held-food-motion-check.json`이 검증 결과다.
