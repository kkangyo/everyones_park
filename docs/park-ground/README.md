# 겨울 공원 바닥 타일

[25종 미리보기와 연결 예시](winter-ground-catalog.png)

기존 바닥 7종과 새 재질 18종을 합쳐 25종이다. 개발 서버의 `/park3d/?edit`에서 ‘바닥 종류’를 선택하면 바닥 도구가 켜진다. 미리보기를 보고 지도에서 한 칸씩 설치한다.

| 구분 | 재질 |
| --- | --- |
| 눈과 잔디 | 완전히 덮인 눈, 푸른 그늘의 눈, 눈 없는 잔디, 눈 조금·반쯤·많이 쌓인 잔디 |
| 산책로 | 기존 흙길, 갈색 벽돌, 틈새에 눈이 쌓인 갈색 벽돌, 회색 블록, 눈이 쌓인 회색 블록, 밝은 판석, 고운 자갈, 짙은 회색 포장길 |
| 연결 | 잔디↔벽돌, 잔디↔회색 블록. 인접한 잔디·눈 타일을 보고 연결 방향과 눈의 양을 자동 적용 |
| 호수 주변 | 얼어붙은 흙과 눈, 둥근 조약돌, 석축 가장자리, 마른 풀과 눈, 푸른 눈 둔덕, 얼어붙은 호수 |
| 기존 바닥 | 목교, 광장, 무대 |

호숫가 타일은 이웃에 얼음이 있으면 물가 쪽 가장자리에 젖은 듯한 색이나 푸른 그늘을 더한다. 호숫가 바닥은 걸을 수 있고 얼음은 기존과 같이 통행을 막는다. 바닥을 교체하면 충돌도 함께 갱신되며, 되돌리기와 저장을 지원한다.

메인 화면과 편집기는 `apps/client/park3d/ground.js`의 같은 생성기를 사용한다. 현재 지도 전체를 새 타일로 자동 교체하지는 않는다. 원하는 위치에 직접 설치한다. 원본 지도의 기본 타일 ID는 유지하고 추가 재질을 `editor3d.groundStyles`에 칸별로 저장한다. 따라서 서버 충돌과 기존 2D 타일셋의 타일 번호는 늘리지 않아도 된다. 2D 화면에는 기존 기본 재질로 표시된다.

확인용 이미지 자산도 제공한다.

- `assets/tiles/winter-surfaces.png`: 32×32px 셀, 5열의 25종 아틀라스.
- `assets/tiles/winter-surfaces.json`: 재질 ID·이름·기본 타일·이미지 좌표.
- 런타임 텍스처는 각 칸당 16×16px로 생성한 뒤 지도 전체에 합성한다. 위치에 따른 얼룩과 이웃 타일 연결 때문에 아틀라스의 한 칸 반복과는 차이가 있다.

개발 환경에 Playwright가 있으면 `node scripts/review-park-ground.cjs`로 미리보기·아틀라스와 검사 결과를 다시 만든다. 한글 글꼴이 없는 환경에서는 `PARK_REVIEW_FONT`에 글꼴 파일을 지정한다. 이 검사는 모든 표면의 유효한 색상, 눈 양의 증가, 네 방향 경계 연결을 확인한다. `node scripts/review-map-editor.cjs`는 실제 편집기 클릭, 저장 형식, 재불러온 3D 텍스처, 되돌리기, 얼음 충돌까지 확인한다.
