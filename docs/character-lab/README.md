# 민트 패딩 캐릭터 · 적용 전 3D 시제품

개발 서버에서 `/park3d/character-lab/`에 접속한다. 기존 게임에는 연결하지 않은 독립 화면이다. `pnpm --filter @park/client dev`로 실행하며 기본 포트는 5173이다. 기존 `copy-park3d.mjs`가 빌드 결과에도 함께 복사한다.

첫 번째 참고 이미지의 갈색 긴 머리, 큰 보라색 눈, 민트 패딩, 크림색 털 장식, 분홍 리본, 하트, 갈색 부츠를 절차적 메시로 재현한 비율·동작 검토용 예제다. 두 번째와 세 번째 이미지의 의상은 구현하지 않았다. 이미지와 동일한 머릿결, 섬유 질감, 정교한 의상 실루엣을 완성하려면 별도의 고품질 모델링과 텍스처 제작이 필요하다.

- Three.js r128: 저장소의 기존 엔진을 사용하며 외부 CDN 요청 없음.
- `apps/client/park3d/character-lab/model.js`: 독립 모델 생성기. 얼굴·눈·머리카락 모두 머리 그룹에 결합.
- `studio.js`: 조명, 카메라, 드래그 회전, 휠·핀치 확대, 대기·걷기·손 흔들기·점프, 눈 깜빡임.
- 자동 회전, 일시정지, 정면 복귀 지원. 실제 이동 경로 및 게임 네트워크 연동은 포함하지 않는다.

검증: JS 구문 검사, 클라이언트 타입 검사 및 프로덕션 빌드 통과. Playwright Chromium에서 정면·후면·모바일 화면, 세 동작의 관절 변화, 브라우저 오류 없음 확인. 스크린샷 환경에는 한글 글꼴이 없어 일부 문자가 네모로 보일 수 있다.
